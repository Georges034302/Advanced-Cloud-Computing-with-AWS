# Lab 1.C: Host a Static Website on AWS Lightsail

## Overview
This lab introduces **AWS Lightsail**, a simplified platform for deploying and managing virtual private servers (VPS). You will create a Lightsail instance, install a web server, host a static HTML site, and verify its availability from the public internet.

---

## Objectives
- Create a new AWS Lightsail instance
- Configure networking and access settings
- Deploy a static HTML website using Apache
- Test public access to the site
- Clean up resources to prevent ongoing charges

---

## Architecture Diagram (Conceptual)
```
Internet → Lightsail Instance (Ubuntu)
          ├── Apache Web Server
          └── /var/www/html/index.html (Static Website)
```

---

## Prerequisites
- AWS account with Lightsail access
- SSH key pair (automatically generated by Lightsail or imported manually)
- Basic familiarity with Linux commands

---

## Step 1. Create a Lightsail Instance

1. Sign in to the **AWS Management Console** → Navigate to **Lightsail**.  
2. Choose **Create instance**.  
3. Under *Instance location*, choose your desired region.  
4. Under *Select a platform*, choose **Linux/Unix**.  
5. Under *Select a blueprint*, choose **OS Only → Ubuntu 22.04 LTS**.  
6. Choose the **$5 USD/month** plan (or the lowest tier).  
7. Name your instance: `lightsail-web`.  
8. Click **Create instance**.

Wait a few minutes for the instance to initialize.

---

## Step 2. Connect to Your Instance

Once the instance is running:
```bash
# From the Lightsail console, click the SSH terminal icon, or use your local SSH client:
ssh -i ~/Downloads/LightsailDefaultKey.pem ubuntu@<PUBLIC_IP>
```

Confirm network connectivity:
```bash
ping -c 2 google.com
```

---

## Step 3. Install and Configure Apache Web Server

```bash
# Update packages
sudo apt update -y

# Install Apache
sudo apt install apache2 -y

# Start and enable the service
sudo systemctl start apache2
sudo systemctl enable apache2

# Verify status
sudo systemctl status apache2
```

Check your instance’s **Public IP** in the Lightsail console, then open it in your browser:  
👉 `http://<PUBLIC_IP>` — you should see the default Apache welcome page.

---

## Step 4. Deploy Your Static Website

Replace the default web page with your custom site:
```bash
# Navigate to the web root
cd /var/www/html

# Remove the default index file
sudo rm index.html

# Create a new custom HTML file
echo '<!DOCTYPE html>
<html>
<head><title>My Lightsail Site</title></head>
<body style="font-family: Arial; text-align:center;">
<h1>Welcome to My AWS Lightsail Website!</h1>
<p>This static site is hosted on a Lightsail instance.</p>
</body>
</html>' | sudo tee index.html
```

Test again in your browser using your instance’s public IP — you should now see your custom page.

---

## Step 5. Configure Networking (Optional)

To allow external HTTP access:
1. Go to **Networking** tab in Lightsail.  
2. Under *Firewall*, ensure port **80 (HTTP)** is open.  
3. (Optional) Add port **443 (HTTPS)** if you plan to enable SSL later.

---

## Step 6. Validate the Deployment

Run the following command to confirm site availability:
```bash
curl http://<PUBLIC_IP>
```
✅ You should receive the HTML output of your static page.

---

## Step 7. Cleanup

To avoid ongoing costs:
1. Go to the Lightsail **Instances** tab.  
2. Select your instance → click **⋮ → Delete**.  
3. Confirm deletion.  

This will also remove associated storage and IP allocations.

---

## Summary

In this lab, you have:
- Created a Lightsail instance from scratch
- Installed and configured an Apache web server
- Deployed a static HTML website
- Verified public access via browser and CLI
- Cleaned up all resources after testing

This simple exercise demonstrates how Lightsail provides a fast, low-cost entry point into AWS compute for small web workloads.
